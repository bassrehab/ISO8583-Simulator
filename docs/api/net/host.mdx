## `Rule`

```python
Rule(
    mti: list[str] = list(),
    pan_prefix: list[str] = list(),
    amount_gt: int | None = None,
    amount_lt: int | None = None,
    network: str | None = None,
    fields: dict[int, str] = dict(),
    respond: str = '00',
    action: str = 'respond',
    delay_ms: int = 0,

```

One response rule. The first rule whose conditions all match is used.

**Attributes**

<ResponseField name="mti" type="list[str]">
  Request MTIs this rule applies to (any when empty)
</ResponseField>

<ResponseField name="pan_prefix" type="list[str]">
  Only match cards whose PAN starts with one of these
</ResponseField>

<ResponseField name="amount_gt" type="int | None">
  Only match when field 4 is greater than this (minor units)
</ResponseField>

<ResponseField name="amount_lt" type="int | None">
  Only match when field 4 is less than this (minor units)
</ResponseField>

<ResponseField name="network" type="str | None">
  Only match this card network (e.g. "VISA")
</ResponseField>

<ResponseField name="fields" type="dict[int, str]">
  Only match when these fields have exactly these values
</ResponseField>

<ResponseField name="respond" type="str">
  Response code for field 39
</ResponseField>

<ResponseField name="action" type="str">
  "respond" (default), "drop" (never answer, to test timeouts) or
"close" (close the connection)
</ResponseField>

<ResponseField name="delay_ms" type="int">
  Wait this long before answering
</ResponseField>

## `MockHost`

```python
MockHost(
    rules: list[Rule] | None = None,
    wire_format: WireFormat | None = None,
    framing: Framing | None = None,
    version: ISO8583Version = ISO8583Version.V1987,

```

A mock issuer host for testing acquirer and switch software.

**Example**

```python
host = MockHost(rules=[Rule(amount_gt=100000, respond="51"), Rule()])
server = await host.start("127.0.0.1", 8583)
```
