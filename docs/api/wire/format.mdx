## `WireFormat`

```python
WireFormat(
    mti: Encoding = Encoding.ASCII,
    bitmap: str = 'binary',
    length_prefix: Encoding = Encoding.ASCII,
    numeric: Encoding = Encoding.ASCII,
    text: Encoding = Encoding.ASCII,
    binary_fields: str = 'raw',
    ebcdic_codec: str = 'cp037',
    bcd_odd_padding: str = 'left',
)
```

Byte layout of a message. Each part of the message can be encoded independently.

**Attributes**

<ResponseField name="mti" type="Encoding">
  MTI encoding: ASCII, EBCDIC or BCD
</ResponseField>

<ResponseField name="bitmap" type="str">
  "binary" for 8 raw bytes per bitmap, or "hex" for 16 hex characters in
the text encoding
</ResponseField>

<ResponseField name="length_prefix" type="Encoding">
  Encoding of LLVAR / LLLVAR length indicators: ASCII, EBCDIC, BCD or BINARY
</ResponseField>

<ResponseField name="numeric" type="Encoding">
  Encoding of numeric field content: ASCII, EBCDIC or BCD
</ResponseField>

<ResponseField name="text" type="Encoding">
  Encoding of alphanumeric content: ASCII or EBCDIC
</ResponseField>

<ResponseField name="binary_fields" type="str">
  "raw" to send binary fields (PIN block, MAC, EMV) as bytes, or "hex"
to send them as hex characters in the text encoding
</ResponseField>

<ResponseField name="ebcdic_codec" type="str">
  Python codec used for EBCDIC (cp037 is US/Canada, cp500 international)
</ResponseField>

<ResponseField name="bcd_odd_padding" type="str">
  Filler nibble position for odd-length variable BCD fields
</ResponseField>

