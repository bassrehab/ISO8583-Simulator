iso8583sim is a toolkit for card payment messages. It covers the 1987, 1993 and 2003 versions of ISO 8583 and the VISA, Mastercard, AMEX, Discover, JCB and UnionPay networks, from a single message up to a mock issuer host under load.

```bash
pip install iso8583sim
```

```python
from iso8583sim.core.builder import ISO8583Builder
from iso8583sim.core.parser import ISO8583Parser
from iso8583sim.core.samples import sample_message

# A VISA authorization request for 25.00
raw = ISO8583Builder().build(sample_message(amount_minor_units=2500))

message = ISO8583Parser().parse(raw)
print(message.mti, message.network, message.fields[4])
# 0100 CardNetwork.VISA 000000002500
```

## Performance

With the compiled extensions (included in the wheels for Linux, macOS and Windows), iso8583sim parses about 180,000 messages per second on Apple Silicon. See [Performance](./performance) for the numbers and tuning.
